## Plan — 고정할 MVP

목적은 한국산업인력공단 국가기술자격의 공식 일정·통계를 이해하고 비교한 뒤, 공부 가능시간에 맞는 준비 계획을 해당 브라우저에 저장하도록 돕는 것이다. 모바일 우선이며 공식 접수는 검증된 기관 링크로 연결한다.

| 구분 | MVP 요구사항 |
|---|---|
| 탐색·상세 | 검증된 이름·별칭·등급·분야 검색, 종목 상세, 필기·실기 접수/시험/발표 구분, 출처·확인일 |
| 일정·통계 | 한국 날짜 기준 일정·D-day, 최근 최대 5개 완료연도의 실제 제공 통계, 표본 수·범위·불완전성 표시 |

| 개인 준비 | 최대 10개 관심 종목, 규칙 기반 계획·수정·삭제·체크, localStorage, ICS·JSON 내보내기 |
| 신뢰·운영 | 최소 운영자 인증·검토·게시 제어·정정 이력, 출처·방법론·정책, 서버 HTML·검색 설정 |
| 광고·분석 | 기본 OFF 구조, 승인된 환경·정책·동의·운영자 설정에 따른 후속 활성화, 개인 학습 내용 수집 금지 |

방문자 회원가입·계정 동기화·알림 발송·자동 원서접수·개인 응시자격 확정·합격확률 예측·실시간 LLM/AI 챗봇·커뮤니티·기출문제 수집·유료 강의·JSON 가져오기는 이번 MVP에 추가하지 않는다. 최소 운영자 로그인은 방문자 회원가입과 별도 P0다. 컴퓨터활용능력, 다른 시행기관·국가전문자격·민간자격·어학시험, 과정평가형·일학습병행, 상시시험 좌석 현황도 기본 지원에 섞지 않는다.

최초 검증은 **전기기사·전기산업기사·전기기능사**다. 종목명은 검증 대상이며 코드·실제 제공범위는 아직 확정하지 않는다. 공개 목표는 검증된 최대 10종목이며 후보는 전기기사, 산업안전기사, 정보처리기사, 건설안전기사, 소방설비기사(전기분야), 소방설비기사(기계분야), 전기산업기사, 산업안전산업기사, 전기기능사, 위험물기능사다. 인기 순위나 지원 확약이 아니며 자료가 부족하면 공개 종목을 줄인다.

## Validate — STEP-02 실행 계획

다음 항목은 **실행 계획**이다. 본 문서 작성으로 아래 API·도메인·보안 테스트를 실행한 것은 아니다.

1. DS-01(15003024)·DS-02(15074408)·DS-03(15089380)의 공식 공개 operation·요청/응답 필드·format·HTTPS·쿼터 단위/주기·개발/운영 승인 조건을 확인한다. 계정별 실제 승인과 키 활성화는 별도 증거로 남긴다. 구형 HTTP 명세는 자동 강등하지 않고 안전한 공식 경로 확인 전 연결을 보류한다.
2. 승인키를 서버 환경변수로 설정한 뒤 DS-01에서 세 종목의 현재 공식명·문자열 코드·등급·시행 상태를 찾는다. 코드/등급 crosswalk는 공식 근거와 검토 시각을 기록한다. 명세 sample을 live 코드 검증으로 취급하지 않는다.
3. 실행 시 Asia/Seoul 현재 연도를 계산한다. 이 문서 기준 조회 후보는 2026·2027년 일정과 최근 완료연도 2021~2025년 통계이며, 제공 보장이 아니다. 진행 중 2026년 통계는 완료연도와 분리한다. 일정은 종목별, 통계는 실제 등급·연도 단위로 재사용해 중복 호출을 줄인다.
4. 세 종목 각각 코드·연도·회차·필기/실기·접수/시험/발표·날짜 정밀도·통계 분모/분자·누락·중복·제공범위를 표로 남긴다. 표본 일정·통계를 Q-Net 등 공식 원문과 대조하고 자동검증/사람 대조를 분리한다.
5. 단건/다건/빈/null item·totalCount 문자열/정수·pagination 중간 실패·HTTP 200 업무 오류·인증/쿼터/429/500/timeout·깨진 XML/JSON·HTML 오류·과대 응답·DOCTYPE/외부 엔티티 차단·중복·정정·불명확 이름·통계 불일치를 테스트 대상으로 준비한다. recorded 응답은 비밀 제거 후 출처·수집시각·해시를 기록하고 synthetic와 분리한다.
6. 승인·키가 없으면 live 항목은 BLOCKED/NOT_RUN으로 유지한다. 빈 응답은 EMPTY_UNCONFIRMED로 남기며 NOT_PROVIDED는 실제 공식 근거가 있을 때만 사용한다. G0는 종목별 의미·범위·정확성 근거가 갖춰질 때 판정한다.

독립적인 후속 단위 테스트의 수용 예시는 가중 합격률 `(20+450)/(100+900)=47.0%`, 누락/0 분모→null, 40%→45%는 +5%p, 한국 날짜 경계·윤일, 7일 공부 가능시간 11시간, ICS 배타적 종료일이다. 이는 테스트 입력·기대값이며 운영 통계 또는 현재 테스트 통과 결과가 아니다.

## Report — STEP-03 기반 준비안과 경계

STEP-01 근거와 STEP-02 데이터 계약 검토 후 Next.js App Router·TypeScript strict·패키지 관리자 하나·lockfile·린트·단위 테스트·브라우저 E2E 기반을 선택한다. 버전·명령은 해당 시점 공식 지원과 실제 CLI 도움말로 확인한다. 안전한 XML 파서·날짜·ICS 라이브러리는 필요한 최소 수로 선정하고 라이선스·유지보수·번들 영향을 기록한다.

공공 API 수집은 서버 경계로 두고 방문자 요청과 분리한다. fixture/live 데이터 모드, 운영 fixture 차단, secret 비노출, 광고/분석 기본 OFF를 초기 설정에 명시한다. 날짜·통계·계획 계산은 외부 API 없이 검증 가능한 순수 함수로 준비한다. fixture 성공은 live 연동 성공과 별도 상태다. DB 원격 연결·migration/RLS 실행·배포는 후속 단계와 승인 대상이며 이번 문서 작업에 포함되지 않는다.

다음 작업은 **STEP-02 — API 승인·3종목 데이터 가능성 검증(v1 TASK-002·003)**이다. 키가 없더라도 계약·synthetic 테스트 설계 준비는 가능하지만 live 수집·G0·공개 지원 판정은 남는다.
