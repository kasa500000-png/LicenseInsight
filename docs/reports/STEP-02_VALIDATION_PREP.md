## 지금 확인된 경계

- 이번 세션의 환경 점검에서 `DATA_GO_KR_SERVICE_KEY`가 없었다. 키 값은 열람·출력하지 않았다.
- DS-01~03의 공식 공개 카탈로그 조회에서 HTTP 503을 관측했다. 이번 세션에서 공개 명세 재확인에 성공한 것으로 기록하지 않는다. 상세 요청 증거는 [공개 카탈로그 점검 보고서](API_CATALOG_AUDIT.md)를 따른다.
- 패키지의 명세 설명은 검증 준비를 위한 기존 참고자료다. operation, 필드, HTTPS 지원, 코드, 승인·쿼터를 이번 세션에서 검증한 사실로 승격하지 않는다.
- API 인증 요청, 개발·운영 승인 조회, 공식 일정·통계 대조, 파서·계산 테스트는 모두 NOT_RUN이다. 카탈로그 HTTP 503은 실제 API 게이트웨이의 장애나 데이터 미제공을 증명하지 않는다.

## 실행 순서와 종료 조건 — PLANNED

1. DS-01(15003024), DS-02(15074408), DS-03(15089380)의 공개 명세 접근이 복구되면 공식 HTTPS 경로·operation·요청 키 대소문자·format·업무 결과코드·pagination을 기록한다. DS-04 설명과 DS-05 수수료는 후속 범위로 남기며 수수료를 필수 성공 조건으로 확대하지 않는다.
2. DS별 개발·운영 승인과 키 설정·활성화, 쿼터를 별도로 확인한다. 실제 호출 전 페이지 수·조회 구간·재시도 상한으로 호출 예산을 정한다. 키나 승인 부재 시 인증 요청을 만들지 않고 차단 근거만 기록한다.
3. DS-01의 실제 전체 페이지에서 세 대상의 공식명·문자열 코드·등급·시행 여부를 찾는다. 코드 앞자리 0을 보존하고 이름이 중복되거나 변경됐다면 검토로 보낸다.
4. DS-01 `seriescd`와 DS-03 `grdCd`를 같은 값으로 취급하지 않는다. 실제 명세·응답 근거로 원천 코드/이름/등급/적용연도 → 내부 종목의 정확한 1:1 crosswalk를 작성한다. 검토자와 근거가 없는 유사명 매칭은 공개 불가다.
5. 검증한 코드로 DS-02의 2026·2027 일정에서 필기/실기, 접수/시험/발표, 추가·빈자리접수, 단일일/기간, 날짜/시각 정밀도를 확인한다. 빈 응답은 `EMPTY_UNCONFIRMED`로 기록한다. 공식 근거 없이 `not_announced` 또는 `NOT_PROVIDED`로 판정하지 않는다.
6. 검증한 등급·연도 단위로 DS-03을 수집하고 세 종목에 매핑한다. 같은 전체 통계를 종목마다 중복 호출하지 않는다. 2021~2025 각 연도에 실제 회차·필기/실기·취득방식·응시자·합격자·공식 비율·누락/중복·범위 상태를 기록한다. 범위가 좁으면 확인된 연도만 남긴다.
7. 종목마다 일정과 통계 표본을 공식 원문과 대조한다. `source_published_at`(알 수 없으면 null), `fetched_at`, `validated_at`, `reviewed_at`를 별도 보관한다. API 카탈로그 수정일을 시험 공고일로 대체하지 않는다.
8. 승인/키/operation/응답/공식 대조/공개 범위를 [API 검증 보고서 템플릿](../../templates/API_VALIDATION_REPORT.md)에 기록한다. 키·Authorization·민감 쿼리가 제거된 실제 응답만 STEP-02 이후 `tests/fixtures/recorded`에 저장한다. 이번 M0에는 recorded 응답을 만들지 않았다.

## 필요한 설정과 독립 진행

`DATA_GO_KR_SERVICE_KEY`는 사용자 로컬 서버 환경 또는 해당 프로젝트의 secret manager에 설정한다. 실제 키를 채팅·명령행 인수·스크린샷·Git 파일에 넣지 않는다. API별 키가 다르면 서버 변수 이름을 분리하고 매핑을 기록한다. `.env`/인증 상태 파일을 열어 내용을 출력하지 않는다. 존재 확인만으로 승인·유효성을 판정하지 않는다.

추후 환경은 `APP_ENV=local|test|preview|production`, `DATA_MODE=fixture|live`, `ADS_ENABLED=false`, `ANALYTICS_ENABLED=false`를 서버에서 구분하도록 설계한다. 이번 문서 작성은 환경을 실제 설정하거나 운영 차단을 구현한 것이 아니다.

키가 없어도 테스트 사례·명세 비교표·null 코드 검증 대장·crosswalk 양식·공개 차단 기준을 검토할 수 있다. 이번 M0에서는 이 문서와 준비 JSON까지만 작성했다. 파서 구현, synthetic fixture 생성, 테스트 러너·앱 초기화는 수행하지 않았다. 인증 실호출·실제 제공범위·공식 대조가 없으므로 G0는 미충족이다.
