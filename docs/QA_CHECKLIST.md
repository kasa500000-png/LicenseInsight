# 출시 QA 체크리스트

> v2 구현 패키지: 기존 제품 범위를 유지한다. 상세 구현 규칙은 ARCHITECTURE.md, DATABASE.md, DOMAIN_RULES.md, ROADMAP.md를 함께 적용한다. 모든 구현·API 인증 호출·배포 상태는 현재 미실행이다.


상태: 전 항목 미검증. 문서 생성은 기능 검증이 아니다.
체크 결과에는 환경·커밋·데이터 기준일·실행일·검증자를 함께 기록한다.

## 데이터·계산

- [ ] 승인된 키로 각 필수 API 실호출 성공. 키를 증거에 노출하지 않음.
- [ ] HTTPS 또는 검토된 안전한 공식 연동 경로 확인. 자동 HTTP 강등 없음.
- [ ] 종목 코드 문자열 앞자리 0과 등급별 코드 체계를 보존.
- [ ] 초기 3종목의 공식 일정·통계 대조와 공개 후보별 지원 범위 기록.
- [ ] API별 XML/JSON, 단건/다건/빈 결과/오류/XML 외부엔티티 방지 확인.
- [ ] pagination 일부 실패를 전체 성공으로 처리하지 않음.
- [ ] 원천 종목명 매핑이 모호하면 공개 보류.
- [ ] 날짜/기간/정밀 시각과 한국 시간대 구분.
- [ ] 접수 마감 시각 미제공 시 23:59 등 임의 시각을 넣지 않음.
- [ ] CBT 등 시험기간을 개인의 확정 시험일로 표시하지 않음.
- [ ] 자정·월말·연말·윤일·다른 기기 시간대의 D-day 확인.
- [ ] 공식 미발표, 미지원, 미확인, 수집 오류를 구분.
- [ ] 합격률 20/100 + 450/900 → 47.0% 테스트 통과.
- [ ] 응시자 누락·0명은 0%로 바꾸지 않음.
- [ ] 필기·실기·취득방식·회차 중복 분리.
- [ ] 진행 중 연도·누락 회차가 있는 집계를 공식 완전 연간 수치로 표시하지 않음.
- [ ] 40%→45% 변화는 +5%p로 표시.
- [ ] 차트·표·비교·상세 값 일치.
- [ ] 비율만으로 응시자 수 역산, 합격률 곱으로 개인 최종 확률 생성 없음.
- [ ] 동일 응답 재수집 시 중복·정상값 삭제 없음.
- [ ] 날짜 정정이 새로운 별도 일정으로 복제되지 않음.

## 핵심 여정·UX

- [ ] 검색→상세→관심 저장→계획 저장→ICS 내보내기 E2E 통과.
- [ ] 모바일 첫 화면에서 종목명과 다음 행동 확인 가능.
- [ ] 360/390/768/1440px 화면 점검 및 스크린샷 기록.
- [ ] 키보드·포커스·버튼 라벨·차트 표·대비 확인.
- [ ] 2~3개 비교와 잘못된/중복 ID·미지원 연도 처리가 안전함.
- [ ] 새로고침 이후 브라우저 저장 유지.
- [ ] localStorage 거부·손상·용량 초과에서도 조회 가능.
- [ ] 브라우저 데이터 삭제·기기 변경 시 개인 기록 소실 가능성 안내.
- [ ] 계획 입력 0시간·과거일·모든 날짜 제외 시 정상 안내.
- [ ] 7일 구간 평일1시간/주말3시간 → 11시간; 배정량 초과 없음.
- [ ] ICS 기간 끝 날짜가 표준의 배타적 종료 규칙을 지킴.
- [ ] ICS 한국어·UID·날짜·출처 파서 검증 및 실제 캘린더 가져오기 기록.
- [ ] ICS가 자동 업데이트나 시험접수 완료 기능이 아님을 안내.

## 보안·운영

- [ ] 브라우저 번들·소스맵·로그·fixture·커밋에 비밀키 없음.
- [ ] 공개 스키마 RLS·명시적 grants·게시 데이터만 읽기 적용.
- [ ] 익명·일반 인증 사용자에게 모든 관리 쓰기·원문 읽기 차단.
- [ ] 사용자 수정 메타데이터로 운영자 권한 상승 불가.
- [ ] 관리자 수동 동기화 인증·권한·속도 제한·감사로그 적용.
- [ ] privileged view/function의 권한 우회 검사.
- [ ] 외부 HTML/Markdown 정제·URL 프로토콜/기관 도메인 검증.
- [ ] 외부 응답을 도구 실행 지시나 시스템 프롬프트로 처리하지 않음.
- [ ] 수집 실패 시 정상 캐시 유지와 갱신 지연 표시.
- [ ] 원문 확인 시각과 공식 발표 시각 분리.
- [ ] API별 호출 예산·재시도 상한·동시 작업 잠금 적용.
- [ ] DB·콘텐츠·설정 백업·복원 연습·운영 롤백 증거 존재.
- [ ] 실제 운영 비용·상업 호스팅 조건 확인과 지출 경보 설정.
- [ ] 가상 데이터는 개발/preview만 사용; 운영이 mock 모드로 배포되면 차단.
- [ ] 코드·DB·환경변수 변경 내역과 운영 배포 승인 기록.

## 검색·콘텐츠

- [ ] 서버 HTML에 핵심 공개 콘텐츠 포함.
- [ ] 운영 도메인 canonical·title·description·OG 검증.
- [ ] sitemap은 게시·검증된 대표 페이지만 포함.
- [ ] 검색/필터/비교 조합 무한 색인 없음.
- [ ] preview·admin·내 준비는 적절히 색인 차단; 보안은 인증으로 처리.
- [ ] 실제 내용에 맞는 구조화 데이터만 사용.
- [ ] 일정 변경·종목 폐지·존재하지 않는 URL의 상태코드 확인.
- [ ] 편집 콘텐츠의 출처·검토일·계산법·해석상의 한계 검수.
- [ ] 공식 기관 운영처럼 보이는 표현, 조작된 후기·방문자 수 없음.
- [ ] 운영자 정보·정정 연락처·개인정보·광고/분석 안내 실제 설정과 일치.

## 광고·측정

- [ ] 개발·preview·자동화 테스트·admin·오류·개인 계획에서 실광고 요청 0.
- [ ] 운영 광고 기본 OFF; 승인·정책 검토·운영자 동의 후만 활성화.
- [ ] 자기 실광고·자동화 실광고 클릭·인위적 반복 노출 없음.
- [ ] 광고 차단·스크립트 실패·동의 거부 시 기능 정상.
- [ ] 광고가 접수·저장·다운로드 버튼에 붙어 오클릭을 유도하지 않음.
- [ ] 광고 스크립트 ON/OFF 각각 성능·레이아웃 이동 확인.
- [ ] 공개 페이지 모바일 목표 LCP≤2.5초, INP≤200ms, CLS≤0.1 검토.
- [ ] 정책·실제 대상 지역에 필요한 동의 설정 검토와 반영.
- [ ] 게시자 ID·ads.txt는 실제 승인 계정 값 사용.
- [ ] 긴급 광고 비활성화 테스트.
- [ ] 분석 이벤트가 개발/봇·중복·개인 자유문구로 오염되지 않음.
- [ ] 상세 방문 대비 핵심 행동 전환율 계산을 테스트 데이터로 검증.

## 최종 판정

미해결 P0 오류가 있으면 공개 범위를 줄이거나 출시를 보류한다. 외부 API 실호출, 실제 브라우저·캘린더 가져오기, 운영 배포 등을 하지 않았다면 해당 항목을 미검증으로 유지한다. 스크린샷 한 장, 테스트 한 개, 문서 작성만으로 전체 완료를 선언하지 않는다.
