# 구현 계획 진입점 — M0에서 추가한 v2 호환 안내

첨부 v2 패키지에는 이 이름의 파일이 없었다. 사용자 요청의 구현 계획 확인을 위해 기존 [ROADMAP](ROADMAP.md)을 연결한다. 원본 구현 순서와 작업 범위를 변경하지 않는다.

| 사용자·v1 표기 | v2 기준 | 이번 처리 |
|---|---|---|
| M0 / TASK-001 | [STEP-01 프로젝트 점검](../prompts/steps/STEP-01_PROJECT_AUDIT.md) | 저장소·환경·범위·위험·후속 검증 준비 |
| TASK-002·003 | [STEP-02 API proof](../prompts/steps/STEP-02_API_PROOF.md) | 다음 작업; 이번에는 준비 문서만 작성 |
| 개발 기반 | STEP-03 | 후속 계획; 앱·의존성 설치 미수행 |

실제 결과는 [STEP-01 보고서](reports/STEP-01.md), [현재 상태](../state/PROJECT_STATUS.md), [차단 사항](../state/BLOCKERS.md)에 기록한다. MVP와 후속 계획은 [범위·위험 검토](reports/M0_SCOPE_AND_PLAN.md), 3종목 검증 준비는 [STEP-02 준비표](reports/STEP-02_VALIDATION_PREP.md)를 따른다.

공개 명세 확인·계정 승인·인증 실호출·공식 대조는 별도 근거가 필요하다. 구현 계획 문서가 있다는 사실로 어느 항목도 완료 처리하지 않는다.
