# 오류 수정·회귀 검증 프롬프트

```text
자격인사이트의 현재 오류를 수정해라. 프로젝트 전체를 다시 만들지 마라.
AGENTS.md와 현재 STEP 보고서, 관련 PRD/데이터 계약, 실제 코드/로그를 먼저 읽어라.
제공된 오류 메시지·사용자 재현순서·화면을 기준으로 재현하고,
로그가 없거나 도구가 없으면 추정 원인과 확인된 원인을 구분해라.
원인이 날짜/통계/개인저장/수집/권한/광고 중 어디에 속하는지 좁혀라.
수정 전 실패를 재현하는 최소 회귀 테스트를 만들고 최소 변경으로 고쳐라.
환경/의존성 문제라면 실제 버전·공식 문서·--help를 확인하고 동일시도 무한반복을 하지 마라.
null을0으로 바꾸거나 검증/권한을 끄거나 테스트기대값을 버그에 맞춰 성공시키지 마라.
키/원문민감값은 보고서에 남기지 말고 실광고를 클릭하지 마라.
수정후 관련 unit/integration/E2E, UI변경이면 실화면을 검증해라.
원인·변경파일·실행한검증·미실행·영향범위·재발방지를 해당 STEP 보고서에 남겨라.
운영 배포는 이 지시로 자동 허가되지 않는다. 현재 승인 범위를 확인해라.
```
