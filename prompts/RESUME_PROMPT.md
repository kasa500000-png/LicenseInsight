# 중단 후 이어하기 프롬프트

```text
자격인사이트 구현을 이어서 진행해라. 이전 대화를 기억한다고 가정하지 마라.
AGENTS.md, state/PROJECT_STATUS.md, BLOCKERS.md, APPROVALS.md, EVIDENCE_INDEX.md,
docs/ROADMAP.md와 마지막 docs/reports/STEP-NN.md를 읽어라.
현재 Git status/branch/diff/사용 가능한 도구를 확인하고 사용자 변경을 보존해라.
DONE으로 표시된 단계도 다음 작업에 필요한 실제 코드/테스트/화면근거가 있는지 확인해라.
CODE 작성과 live API/운영 공개 완료를 구분하고 증거 없는 완료표시는 수정해라.
다음 미완료 STEP 중 선행조건이 충족된 하나를 선택하고 해당 prompts/steps 파일대로 실행해라.
차단이 있으면 독립 가능한 작업으로 진행하고 원인을 한곳에 기록해라.
새 scaffold·전체 재작성·기존 DB초기화를 하지 마라.
유료/원격변경/배포/실광고는 실제 승인 범위를 확인해라.
Audit→Plan→Implement→Validate→Report 후 상태/근거/다음STEP을 갱신해라.
```
